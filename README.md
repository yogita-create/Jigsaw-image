🧩 **Jigsaw Puzzle Game**

A fully responsive and interactive Jigsaw Puzzle Game designed to deliver a seamless user experience across **mobile, tablet, and desktop platforms**. The application focuses on smooth UI interactions, efficient puzzle logic, and engaging gameplay.

🚀 Key Highlights

- 📱 Cross-platform compatibility (Mobile, Tablet, Desktop)
- 🧩 Dynamic puzzle generation using grid-based logic
- 🖱️ Smooth drag-and-drop interaction
- ⚡ Optimized performance and responsive UI
- 🔄 Replay and reset functionality
🛠️ Tech Stack

- HTML5
- CSS3 (Responsive Design)
- Reactjs

 💡 Core Functionality

- Predefined images are divided into equal grid segments
- Puzzle pieces are randomized programmatically
- Users solve the puzzle via intuitive drag-and-drop interactions
- Real-time UI updates ensure smooth gameplay experience
